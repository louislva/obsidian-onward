It helps without taking over.

Most AI writing tools want to write for you. Onward is built for the moment you already know what you mean but haven't found the words yet.

It waits for you

Nothing appears while you're typing. Pause for two seconds and a suggestion fades in, already fetched in the background, so it's there the moment you look up.

It sounds like you

Onward reads the note you're in, today's and yesterday's journal, and any notes or web pages the note links to. Suggestions pick up your phrasing and what you've actually been thinking about.

It's easy to ignore

Tab accepts, Esc dismisses, and typing anything makes it disappear. On a phone, swipe right on the suggestion to accept it, left to dismiss.

You choose the model

It runs on Claude Opus by default, through OpenRouter, and any other model is one search away. Rank a few: if one fails, the next takes over without you noticing.

Install in a couple of minutes

Onward isn't in Obsidian's plugin directory yet, so it installs through BRAT, the usual installer for plugins in beta. BRAT also keeps Onward up to date.

  1. Get BRAT

    Install and enable BRAT from Obsidian's community plugins.

    Open BRAT

  2. Add Onward

    This link opens BRAT in Obsidian with Onward filled in. Click Add plugin, then turn Onward on under Settings → Community plugins.

    Add Onward to Obsidian

    Link not opening? In BRAT, choose Add beta plugin and paste louislva/obsidian-onward.

  3. Add your key

    Create a key at openrouter.ai and paste it into Settings → Onward. You pay OpenRouter directly for what you use. Then start writing.

Rather install it by hand?
  1. Download main.js, manifest.json and styles.css.
  2. Put them in <your vault>/.obsidian/plugins/onward/.
  3. Restart Obsidian and turn Onward on under Settings → Community plugins.

You'll need to repeat this to update.

What leaves your vault

Each suggestion sends the note you're writing to OpenRouter and the model you picked, along with the recent journal entries and linked notes and pages it reads for context. You can switch that extra context off in settings. Nothing else is sent, and your key is never logged.
